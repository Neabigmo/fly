# 真实果蝇连接组 numerosity 与加法研究

用 **MaleCNS v1.0**（雄性黑腹果蝇完整中枢神经系统连接组）搭建**拓扑冻结、突触强度可训**的可微循环网络，
训练它完成「数点」与「两组点相加」，并与**入度/出度/权重分布完全匹配的随机化连接组**做对照，
回答：真实 wiring 是否提供了 inductive bias？

## 2. 实验设计

```
32×32 点图
   ↓  固定视网膜映射（不训练）
892 个六方柱 × lamina 输入神经元
   ↓  真实 MaleCNS 连接组（拓扑冻结）
神经元活动 h(t)
   ↓  很小的线性读出层
数量 1..5   /   a+b
```

### 核心约束
- **拓扑绝不改变**：`W_ij = 0` 永远保持 0。只有**已存在突触**的增益
  `g_ij = 1 + δ_ij` 可训练，初始 `δ = 0`。
- **输入映射不训练**：图像 → 神经元是固定的双线性采样，保证「是连接组在学，不是前面的 CNN 在学」。
- **读出默认只取 visual projection neurons（VPN）**：排除「线性探针直接读输入层」的平凡解；
  LC11 属于 VPN，因此与真实生物学结果直接对接。

### 动力学
```
h(t+1) = (1-α)·h(t) + α·φ( W h(t) + I(t) + b )
W_ij   = (1+δ_ij) · w_scale · log1p(突触数_ij) / c
```
- `α = 0.2`，`φ = ReLU`，`T = 8`（计数）或 `5+4+5`（加法，中间 4 步为空白延迟）
- `c` = 平均行和；`w_scale` 由 Stage 0 自动校准（候选网格内取活动量健康的最大值）
- 惩罚项 `λ·mean(δ²)`，`λ = 1e-3`，防止偏离真实 wiring 太远

### 刺激条件（防「面积作弊」）
| 条件 | 内容 | 用途 |
|---|---|---|
| **A** 自然 | 位置/半径全随机 | 基线 |
| **B** 面积控制 | 总墨水面积恒定 | 证明不是靠亮度 |
| **C** 面积+包络 | 总面积恒定且点分布在固定半径圆环上 | 最强控制 |
| **D** 未见布局 | 规则 3×3 网格（朝向/尺度随机） | 布局泛化 |

### 对照
- **Shuffled Fly**：加权双重边交换，**严格保持**每个神经元的入度、出度与**权重多重集**，
  唯一变化是「谁连谁」→ 参数量完全相同。
- **M0 / M1**：M0 = 冻结网络 + 线性探针（诊断「原始结构是否天然可读」）；
  M1 = 端到端训练增益 + 读出。
- **基线**：面积最近质心、像素逻辑回归、小 CNN（任务难度上限）。

### 五个主指标
Count Accuracy · Area-controlled Accuracy · Addition Accuracy · Unseen-pair Accuracy · **Real − Shuffled gap**

## 5. 关键工程决策（附实测依据）

0. **`w_scale` 是电路特异且步数特异的，必须按任务重新校准。** 连接组递推在
   「全兴奋 + ReLU」下只是**临界稳定**：实测在计数配置（w_scale = 1.0）下，
   平均活动随 t 近似以 1.37×/步 增长（t=5: 0.125, t=6: 0.169, t=7: 0.231, t=8: 0.321），
   到 14 步时已达 3.30、最大 341 —— 计数之所以能工作，只是因为它在发散**之前**就读出了状态。
   加法任务 14 步会直接发散（初始交叉熵 18.5，chance 为 1.95）。
   实测扫描：`w_scale ≤ 0.6` 在 14 步内有界，`≥ 0.8` 发散；加法因此取 **0.5**。
   这是 v1「不区分兴奋/抑制」这一简化的直接后果，也是 Stage 6 引入递质符号的动机。
1. **不能用 `torch.sparse.mm` 直接训练**：它对 `values` 求导会分配稠密 `N×N` 梯度
   （实测 N=96,194 时报错需 **34.47 GiB**）。
   → `flynum/models/sparse_lin.py` 手写 `autograd.Function`：forward 用 **CSR** SpMM，
   backward 手写 `Wᵀg`（转置 CSR）+ 逐边内积求 `gradW`，显存 `O(E)`。
2. **CSR 比 COO 快 24 倍**（1.90 ms vs 45.61 ms，12.5M 非零元）。
3. **转置 CSR 的行列必须互换**，写反会静默算成 `W` 而非 `Wᵀ`（已有回归测试）。
4. **`min_gap` 必须大于 1 像素**：4× 超采样后盒式下采样有 1 像素足迹，
   间距 0.8 px 时会把两点桥接成一个 blob，标签就错了。现取 1.5 px，
   并在生成时用连通域计数强制校验。
5. **刺激版本号进入缓存键**，避免改了生成器却复用旧图。
6. **shuffled 缓存必须存边，不能只存统计量。** 早期版本把 shuffle 的 *统计量* 写进缓存，
   读取时却返回 `sg.pre/sg.post`（即**真实连接组**），于是每个 "shuffled" run 其实都在真实
   图上训练，两个条件的指标**逐位相同** —— 这会伪造出一个「真实与随机无差别」的结论。
   现在缓存同时保存 pre/post/weight，并在每次取得后强制校验：与真实图的边重合率必须
   < 50%、入度/出度/权重多重集必须完全一致，否则报错中止。
   `tests/test_shuffle_cache.py` 专门覆盖这个失败模式。
7. **面积控制的半径必须落在训练半径范围内**：否则「数点测试」会退化成「尺寸泛化测试」。
   约束是 `r_max/r_min ≥ √5`（保证 5 个点能放下也要满足），最终取 `U[1.3, 3.4]`、
   `area_target = 32.2`，使条件 B/C/D 的半径恰好落在 [1.43, 3.20] ⊂ 训练范围。
   `scripts/04_build_stimuli.py` 每次都会断言这一点。
8. **视网膜映射的方向是设计契约**：图像左上必须对应视场左上。曾因 y 轴未翻转而上下镜像；
   对计数无影响，但会与文档矛盾、并让 encoder 配图产生误导。
   `tests/test_stimuli_and_encoder.py` 现在直接检验映射相关性。
9. **bodyId 空间极度稀疏**（max = 1,571,825,087，实际仅 211,577 行），
   稠密查找表需 12.6 GB；改用 `searchsorted` 二分查找，0.03 s 且结果逐元素一致。
10. **run 目录不能复用**：同一配置重跑会以 `_rN` 后缀新建目录，防止两个进程追加到
    同一个 `metrics.jsonl`（曾发生，日志被交错污染且无人察觉）。
11. **训练发散保护**：loss > 25 直接中止该 run，而不是白烧几小时 GPU。
12. **两个脚本的 CLI 默认值必须一致。** `scripts/06` 曾把「读出标准化」默认设为 **开**，
    而 `scripts/07`（跑主网格的那个）默认设为 **关**。于是用 06 做的所有探针实验都在
    发散的配置下运行，一度让我误判「full 电路在任何学习率下都训不起来」——
    实际上把标准化关掉后 full 立刻正常训练（8 epoch 到 val 0.41）。
    教训：把 06 的默认改成与 07 一致，并把「主网格用的是哪一档」写进脚本帮助文本。
13. **`weight_normalization` 有两种模式，默认 `global`。**
    `global` 除以平均行和 —— 保留「突触多的神经元被驱动更强」这一生物学事实，
    也是全部已报告结果所用；但度数异质性极大时（`full` 的最大/平均行和 = **129**，
    core 为 59）度数最高的神经元等效增益达 129×，会主导整个网络。
    `row` 改为每个神经元除以自身行和，使总驱动严格相等；代价是抹掉了驱动强度差异，
    因此是近似而非更优。实测两者对 `full` 的可训练性差异远小于预期。
14. **校准判据必须与任务步数匹配。** 按 t=T 的活动量选 `w_scale` 会选出
    「在任务步数上健康、但在更长时程上发散」的值：core 取 `w_scale=1.0` 时
    32 步内活动增长 **9782 倍**（最大 1.8e6）。计数之所以成立，是因为读出在
    **t=8、发散之前**取状态 —— 这个网络本质上是暂态/前馈式计算，而不是收敛的循环计算。
    `scripts/05_calibrate.py` 现在同时报告两者的判据与完整的 32 步稳定性扫描。
15. **CPU 密集步骤必须多进程并行。** 保度保权重边交换在单个图内是**串行**的
    （每次接受的交换都会改变下一步要校验的边集），12.4M 边的 `full` 单进程要
    **约 40 分钟**，而这段时间 GPU 完全空转；实测单进程 CPU 占用只有 ~20%。
    不同 seed 是**互相独立**的图，因此可以完美并行：
    `scripts/14_make_shuffles.py --circuit full --seeds 0 1 2 --workers 3`
    一个进程一个 seed，并把每个 worker 的 BLAS 线程限制在 2，避免相互抢占。
    训练本身是 GPU-bound（GPU 利用率 ~85%），所以并行的是 CPU 侧，不是训练。

## 6. 成功判据（预先锁定）

| Level | 判据 |
|---|---|
| 0 失败 | real 与 shuffled 都学不好 → 查校准与信号传播，不调任务定义 |
| 1 能学 | real 数点准确率 > 90%（条件 A） |
| 2 有趣 | 终末准确率接近，但 real 在低样本明显更快 → inductive bias |
| 3 很有意思 | real 在 B/C、未见布局、未见加法组合上持续高于 shuffled |
| 4 漂亮 | LC11 敲除显著降低数点/加法，而无关视觉任务保持 |

## 7. 主要结果（完整数据见 `reports/report.md`）

训练配置：`core` 电路、ReLU、`w_scale = 1.0`、`α = 0.2`、`T = 8`、AdamW 3e-3、无读出标准化。
N_train = 20000，M1 = 训练突触增益 + 读出，M0 = 冻结网络 + 线性探针。

| 条件 | M1 real | M1 shuffled | Δ | M0 real | 面积基线 | 像素基线 | CNN |
|---|---|---|---|---|---|---|---|
| A 自然 | **0.769** | 0.663 | **+0.106** | 0.504 | 0.557 | 0.506 | 0.9998 |
| B 面积控制 | **0.599** | 0.405 | **+0.194** | 0.202 | 0.200 | 0.200 | 0.976 |
| C 面积+包络 | **0.895** | 0.418 | **+0.477** | 0.171 | 0.200 | 0.230 | 0.999 |
| D 未见布局 | **0.599** | 0.368 | **+0.230** | 0.187 | 0.200 | 0.214 | 0.998 |

**结论**

1. **Level 1 部分达到**：real 在自然条件下达到 0.769（远超所有线性基线，但未到 0.90）。
2. **Level 2 达到**：real 明显优于同参数量的随机化对照（ΔA = +0.106，ΔC = +0.477）。
3. **Level 3 达到**：优势在面积/包络双重控制与未见布局上更强，而非更弱 ——
   说明 real 学到的是**数量**表征，shuffled 学到的更接近亮度/包络捷径。
4. **M0 → M1 是决定性的**：冻结连接组的线性可读性在控制条件下就是 chance
   （B 0.202 / C 0.171 / D 0.187），而 M1 达到 0.599 / 0.895 / 0.599。
   **连接组提供了基底，但数量计算是训练出来的。**
5. **采样效率曲线有一个明确的拐点**：N ≤ 5000 时 real 与 shuffled 完全无法区分
   （Δ 在 ±0.02 内，甚至略负），N = 20000 时突然拉开 +0.106。
6. **加法（Stage 4-5）没有学会**：训练组合准确率 0.31–0.39（多数类 0.214），
   但留出组合只有 0.00–0.01（chance 0.143）——典型「记住了但没泛化」，
   且 real 与 shuffled 无差别。诊断：加法要求先会数数，而在 8400 样本预算下
   数点本身只有约 0.5。

**主要限定**：`core` 电路只保留 26.4% 的出向突触权重，是「被切除」的制备；
结果回答的是「真实拓扑能否作为 inductive bias」，而不是「果蝇视叶能数点」。

### 7.1 电路完整度阶梯（Stage 6）

`full` 电路保留 91.3% 的出向突触权重（`core` 26.4%），但度数异质性高得多
（最大/平均行和 = 129 vs 59），需要 `--normalization row` 与更小的 `w_scale=0.4`
才能训练；两者固定在 `scripts/run_all.ps1 -Stage 6`。

在 N=5000 上（`core` 在该预算下完全没有 real−shuffled 差距）：

| 条件 | full real | full shuffled | Δ |
|---|---|---|---|
| A 自然 | 0.4874 | 0.4906 | −0.003 |
| B 面积控制 | 0.1832 | 0.1792 | +0.004 |
| C 面积+包络 | 0.1878 | 0.1718 | +0.016 |
| D 未见布局 | 0.1704 | 0.1786 | −0.008 |

**结论**：更完整的电路并没有让优势更早出现 —— 这说明 real > shuffled 是一个
**大样本现象**，而不是「电路被切除」造成的假象。这与「N ≤ 5000 时 core 也无差距」
完全一致，因此强化了主结论的解读。

两点必须同时声明的限定：① 两档用的归一化不同，所以这不是对「完整度」的干净操纵；
② `full` 的随机化弱得多（与真实图重合 **18.2%**，`core` 只有 2.2%），
所以它的差距若存在会是**保守估计**。要让 `full` 达到同样混合程度需要数倍交换轮数。

### 7.2 已知限制

- **递推只是临界稳定**：`core` 在 `w_scale = 1.0` 下 32 步内活动增长约 10⁴ 倍。
  计数能在 t=8 读出，是因为抢在发散之前；这使网络更像**暂态/前馈**计算，
  而不是收敛的循环计算。加法因此必须换更小的 `α`。
- **权重全为正（不区分兴奋/抑制）**：v1 的简化，也是上述不稳定的根源。
  引入 `body-neurotransmitters`（41 MB，已下载）的 GABA/谷氨酸符号是最直接的下一步。
- **读出只取 VPN**：生物上最干净，但可能丢弃 medulla 中的数量信息；
  `--readout all_except_input` 已实现，尚未系统比较。
- **M0 与 M1 的标准化不对称**：M1 关闭、M0 探针内部开启（线性探针的标准做法）。
