# 真实果蝇连接组 numerosity 与加法研究

用 **MaleCNS v1.0**（雄性黑腹果蝇完整中枢神经系统连接组）搭建**拓扑冻结、突触强度可训**的可微循环网络，
训练它完成「数点」与「两组点相加」，并与**入度/出度/权重分布完全匹配的随机化连接组**做对照，
回答：真实 wiring 是否提供了 inductive bias？

## 2. 实验设计

```
32×32 点图
   ↓  固定视网膜映射（不训练）
892 个六方柱 × lamina 输入神经元
   ↓  真实 MaleCNS 连接组（拓扑冻结）
神经元活动 h(t)
   ↓  很小的线性读出层
数量 1..5   /   a+b
```

### 核心约束
- **拓扑绝不改变**：`W_ij = 0` 永远保持 0。只有**已存在突触**的增益
  `g_ij = 1 + δ_ij` 可训练，初始 `δ = 0`。
- **输入映射不训练**：图像 → 神经元是固定的双线性采样，保证「是连接组在学，不是前面的 CNN 在学」。
- **读出默认只取 visual projection neurons（VPN）**：排除「线性探针直接读输入层」的平凡解；
  LC11 属于 VPN，因此与真实生物学结果直接对接。

### 动力学
```
h(t+1) = (1-α)·h(t) + α·φ( W h(t) + I(t) + b )
W_ij   = (1+δ_ij) · w_scale · log1p(突触数_ij) / c
```
- `α = 0.2`，`φ = ReLU`，`T = 8`（计数）或 `5+4+5`（加法，中间 4 步为空白延迟）
- `c` = 平均行和；`w_scale` 由 Stage 0 自动校准（候选网格内取活动量健康的最大值）
- 惩罚项 `λ·mean(δ²)`，`λ = 1e-3`，防止偏离真实 wiring 太远

### 刺激条件（防「面积作弊」）
| 条件 | 内容 | 用途 |
|---|---|---|
| **A** 自然 | 位置/半径全随机 | 基线 |
| **B** 面积控制 | 总墨水面积恒定 | 证明不是靠亮度 |
| **C** 面积+包络 | 总面积恒定且点分布在固定半径圆环上 | 最强控制 |
| **D** 未见布局 | 规则 3×3 网格（朝向/尺度随机） | 布局泛化 |

### 对照
- **Shuffled Fly**：加权双重边交换，**严格保持**每个神经元的入度、出度与**权重多重集**，
  唯一变化是「谁连谁」→ 参数量完全相同。
- **M0 / M1**：M0 = 冻结网络 + 线性探针（诊断「原始结构是否天然可读」）；
  M1 = 端到端训练增益 + 读出。
- **基线**：面积最近质心、像素逻辑回归、小 CNN（任务难度上限）。

### 五个主指标
Count Accuracy · Area-controlled Accuracy · Addition Accuracy · Unseen-pair Accuracy · **Real − Shuffled gap**

## 5. 关键工程决策（附实测依据）

0. **`w_scale` 是电路特异且步数特异的，必须按任务重新校准。** 连接组递推在
   「全兴奋 + ReLU」下只是**临界稳定**：实测在计数配置（w_scale = 1.0）下，
   平均活动随 t 近似以 1.37×/步 增长（t=5: 0.125, t=6: 0.169, t=7: 0.231, t=8: 0.321），
   到 14 步时已达 3.30、最大 341 —— 计数之所以能工作，只是因为它在发散**之前**就读出了状态。
   加法任务 14 步会直接发散（初始交叉熵 18.5，chance 为 1.95）。
   实测扫描：`w_scale ≤ 0.6` 在 14 步内有界，`≥ 0.8` 发散；加法因此取 **0.5**。
   这是 v1「不区分兴奋/抑制」这一简化的直接后果，也是 Stage 6 引入递质符号的动机。
1. **不能用 `torch.sparse.mm` 直接训练**：它对 `values` 求导会分配稠密 `N×N` 梯度
   （实测 N=96,194 时报错需 **34.47 GiB**）。
   → `flynum/models/sparse_lin.py` 手写 `autograd.Function`：forward 用 **CSR** SpMM，
   backward 手写 `Wᵀg`（转置 CSR）+ 逐边内积求 `gradW`，显存 `O(E)`。
2. **CSR 比 COO 快 24 倍**（1.90 ms vs 45.61 ms，12.5M 非零元）。
3. **转置 CSR 的行列必须互换**，写反会静默算成 `W` 而非 `Wᵀ`（已有回归测试）。
4. **`min_gap` 必须大于 1 像素**：4× 超采样后盒式下采样有 1 像素足迹，
   间距 0.8 px 时会把两点桥接成一个 blob，标签就错了。现取 1.5 px，
   并在生成时用连通域计数强制校验。
5. **刺激版本号进入缓存键**，避免改了生成器却复用旧图。
6. **shuffled 缓存必须存边，不能只存统计量。** 早期版本把 shuffle 的 *统计量* 写进缓存，
   读取时却返回 `sg.pre/sg.post`（即**真实连接组**），于是每个 "shuffled" run 其实都在真实
   图上训练，两个条件的指标**逐位相同** —— 这会伪造出一个「真实与随机无差别」的结论。
   现在缓存同时保存 pre/post/weight，并在每次取得后强制校验：与真实图的边重合率必须
   < 50%、入度/出度/权重多重集必须完全一致，否则报错中止。
   `tests/test_shuffle_cache.py` 专门覆盖这个失败模式。
7. **面积控制的半径必须落在训练半径范围内**：否则「数点测试」会退化成「尺寸泛化测试」。
   约束是 `r_max/r_min ≥ √5`（保证 5 个点能放下也要满足），最终取 `U[1.3, 3.4]`、
   `area_target = 32.2`，使条件 B/C/D 的半径恰好落在 [1.43, 3.20] ⊂ 训练范围。
   `scripts/04_build_stimuli.py` 每次都会断言这一点。
8. **视网膜映射的方向是设计契约**：图像左上必须对应视场左上。曾因 y 轴未翻转而上下镜像；
   对计数无影响，但会与文档矛盾、并让 encoder 配图产生误导。
   `tests/test_stimuli_and_encoder.py` 现在直接检验映射相关性。
9. **bodyId 空间极度稀疏**（max = 1,571,825,087，实际仅 211,577 行），
   稠密查找表需 12.6 GB；改用 `searchsorted` 二分查找，0.03 s 且结果逐元素一致。
10. **run 目录不能复用**：同一配置重跑会以 `_rN` 后缀新建目录，防止两个进程追加到
    同一个 `metrics.jsonl`（曾发生，日志被交错污染且无人察觉）。
11. **训练发散保护**：loss > 25 直接中止该 run，而不是白烧几小时 GPU。
12. **两个脚本的 CLI 默认值必须一致。** `scripts/06` 曾把「读出标准化」默认设为 **开**，
    而 `scripts/07`（跑主网格的那个）默认设为 **关**。于是用 06 做的所有探针实验都在
    发散的配置下运行，一度让我误判「full 电路在任何学习率下都训不起来」——
    实际上把标准化关掉后 full 立刻正常训练（8 epoch 到 val 0.41）。
    教训：把 06 的默认改成与 07 一致，并把「主网格用的是哪一档」写进脚本帮助文本。
13. **`weight_normalization` 有两种模式，默认 `global`。**
    `global` 除以平均行和 —— 保留「突触多的神经元被驱动更强」这一生物学事实，
    也是全部已报告结果所用；但度数异质性极大时（`full` 的最大/平均行和 = **129**，
    core 为 59）度数最高的神经元等效增益达 129×，会主导整个网络。
    `row` 改为每个神经元除以自身行和，使总驱动严格相等；代价是抹掉了驱动强度差异，
    因此是近似而非更优。实测两者对 `full` 的可训练性差异远小于预期。
14. **校准判据必须与任务步数匹配。** 按 t=T 的活动量选 `w_scale` 会选出
    「在任务步数上健康、但在更长时程上发散」的值：core 取 `w_scale=1.0` 时
    32 步内活动增长 **9782 倍**（最大 1.8e6）。计数之所以成立，是因为读出在
    **t=8、发散之前**取状态 —— 这个网络本质上是暂态/前馈式计算，而不是收敛的循环计算。
    `scripts/05_calibrate.py` 现在同时报告两者的判据与完整的 32 步稳定性扫描。
15. **CPU 密集步骤必须多进程并行。** 保度保权重边交换在单个图内是**串行**的
    （每次接受的交换都会改变下一步要校验的边集），12.4M 边的 `full` 单进程要
    **约 40 分钟**，而这段时间 GPU 完全空转；实测单进程 CPU 占用只有 ~20%。
    不同 seed 是**互相独立**的图，因此可以完美并行：
    `scripts/14_make_shuffles.py --circuit full --seeds 0 1 2 --workers 3`
    一个进程一个 seed，并把每个 worker 的 BLAS 线程限制在 2，避免相互抢占。
    训练本身是 GPU-bound（GPU 利用率 ~85%），所以并行的是 CPU 侧，不是训练。
16. **训练并行不但无益，而且有害（实测）。** 8 GB 卡上一个 run 就把 GPU 打到 100% 利用率：
    单 worker **0.0357 epoch/s**，2 worker **0.0284**，4 worker **0.0288**；每 epoch 墙钟
    时间 28 s（1 worker）→ 70.5 s（2）→ 139 s（4）。所以 `scripts/18_queue.py` 里所有
    训练块**严格串行**，只有 CPU 侧的 shuffle 生成用多进程。
17. **「样本效率」曲线必须控制优化步数，否则不能归因给数据。**
    原曲线让每个 N 都训 60 个 epoch，于是 N=20000 得到 313×60 = **18 780** 次更新，
    而 N=5000 提前停止在 41–60 epoch、最多 **4 740** 次。曲线上「N=20000 突然出现
    Δ≈0.108」同时伴随着 4 倍的算力增加，因此**不能**解释成「20k 样本激活了拓扑优势」。
    `scripts/15_run_parallel.py --grid fixed_updates` 现在让 N∈{5000, 10000, 20000} 全部
    只花 **18 780** 次更新（`max_steps`，配 step 级 cosine），并让每个 run 的验证点数
    也固定为 60（`eval_every`），使模型选择粒度同样可比。若 Δ 在 N=5000 仍≈0、在
    N=20000 仍≈0.11，则拐点属于数据多样性；若 N=5000 也打开，则原拐点是算力。
    随机图缓存键是 `{circuit}_shuffled_seed{s}_r{rounds}.npz`，**不含 n_train / max_steps**，
    因此等算力块用的对照组与复现块、学习曲线用的是**同一批随机图**（seed 0/1/2）：
    两个块之间的差异不可能来自「换了另一张随机图」。实测各 seed 的保留边比例
    0.021994 / 0.021919 / 0.022073 / 0.022187 / 0.022482，随机化强度一致。
18. **读出标准化会同时放大回传梯度，必须拒绝「寂静读出池」上的标准化。**
    core + w_scale=1.0 下 VPN 读出池的中位标准差只有 **3.5e-5**，而全网峰值活动是 1.6。
    标准化把读出输入放大 ~3e4 倍，`dL/dz = Wᵀ·dL/dlogit / σ` 于是把回传到 **Δg 的梯度
    放大同样倍数**，一个 step 就炸（实测 epoch-0 交叉熵 **600**，更早一次 5834）。
    这正是当年「full 在任何 lr 下都训不起来」的真正原因。现在
    `ConnectomeRNN.MAX_STANDARDIZE_GAIN = 1e3`：放大倍数超过 1000 就直接**拒绝标准化并
    说明原因**，而不是静默训出一个发散模型。全部已报告的 count/add run 都用 `False`，
    因此这条只影响未来复用它的人。
19. **`torch.cuda.is_available()` 不等于「本进程有可用 GPU」。** 实测
    `CUDA_VISIBLE_DEVICES=""` 时它返回 **True** 而 `device_count()` 是 **0**：
    此时 `torch.load(map_location="cuda")` 拒绝反序列化、`get_device_properties(0)` 直接
    raise。所有模块现在用 `flynum/devices.pick_device()`（判 `device_count()>0`），
    checkpoint 一律 `map_location="cpu"` 再 `load_state_dict`。
20. **统计单位是「训练好的模型」，不是测试图像。** 5000 张测试图由同一个网络打分，
    不是 5000 个独立观测；按图像算 95% CI 会窄一个数量级（实测 A 条件 1×、C 条件 **10×**
    偏窄）。`scripts/20_seed_stats.py` 一律**按 seed 配对**（每个 shuffled seed 是一张
    独立的随机图）报告：两臂均值±95% CI、配对差 Δ 的均值±95% CI、Cohen's d_z、
    Hedges' g、配对 t 与 Wilcoxon；图像级 CI 只作为对照打印出来。
21. **排队前先跑 CPU 冒烟测试。** `scripts/19_smoke.py` 用隔离的刺激缓存（把
    `flynum.train.data.STIM_DIR` 指向 `.cache/smoke`，因为 count 缓存键**不含 `n_test`**，
    否则会覆盖真实测试集）在 CPU 上把排队里的每条代码路径各跑一遍：config 往返、
    签名动力学、固定步数预算、标准化拒绝、三头课程+热启动、损伤面板。它在 20 h 的
    GPU 排队之前抓出了 4 个真 bug（`head_classes` 未接线、`evaluate_with_lesion` 的
    字典/对象不一致、读出标准化放大、`from_dict` 拒绝 run config 的注解键）。
22. **保度保权重的随机交换并不保持「工作点」——这是本次审计发现的一个真问题。**
    实测（`scripts/23_graph_spectrum.py`，幂迭代）：

    | 图 | 谱半径 ρ | 最大奇异值 | t=32 峰值\|h\| | 增长倍数 |
    |---|---|---|---|---|
    | real | **3.9460** | 4.4654 | 1.92e6 | ×8.73e6 |
    | shuffled s0/s1/s2 | **2.7974 / 2.8034 / 2.7986** | ~3.95 | ~2.4e4 | ~×1.1e5 |
    | shuffled（等谱匹配，w_scale=1.4106） | **3.9460** | 5.5723 | 2.16e6 | ×9.82e6 |

    随机图保留入度、出度与权重多重集，但**谱半径低 29%**，32 步内峰值活动差 **1.9 个数量级**。
    因此常规的 real-vs-shuffled 比较**同时改变了「布线」与「放大倍率」**，
    差距里有多少来自布线原先无法区分 —— 这是一个必须声明的限定。

    **换个说法才是重点**：三张独立随机图的 ρ 彼此标准差只有 **0.0032（0.11%）**，
    而真实图比它们**高出 359 个标准差**、比三张图的全部取值范围还高 **40.8%**。
    也就是说，在「同一度数序列 + 同一批突触权重」所能连成的所有图里，
    **真实连接组在决定信号放大倍率的这个量上是一个极端离群值** ——
    这本身就是「真实布线非同一般」的独立结构证据，也正是必须做等谱匹配对照的理由。

    **修正**：权重矩阵对 `w_scale` 严格线性，故把随机图的 `w_scale` 乘以
    ρ_real/ρ_shuffled = 1.4106 即可让两者谱半径相差 **0.000%**，活动增长只差 12%：

### 6.1 等算力对照的判定规则（在结果出来之前写死）

这是最容易被事后合理化的一步，所以先把两种结果各自的含义写下来。判据只用一个数：
**Δ(N) = mean_real(A) − mean_shuffled(A)**，按 seed 配对，单位是训练好的模型；
`Δ(N=20000, 60 ep) = +0.108`（3 seeds）作为基准。

| 观察到 | 结论 | 允许写进论文的话 |
|---|---|---|
| Δ(5000, 等算力) ≤ 0.02 且 Δ(20000, 等算力) ≥ 0.08 | 拐点是**数据多样性** | 「拓扑优势需要足够多的不同刺激才显现」 |
| Δ(5000, 等算力) ≥ 0.06 | 原拐点是**算力**，不是样本量 | 必须改写第 7.3 节，并撤回「大样本现象」的说法 |
| 0.02 < Δ(5000) < 0.06 | 两者都有贡献 | 报告为混合效应，不给单一归因 |
| Δ(20000, 等算力) 与 +0.108 相差 > 0.03 | 算力/max_steps 机制本身改变了结果 | 先查 `max_steps` 与 step 级 cosine，暂停解读 |

同时要求：`optimizer_steps` 必须**恰好等于 18780**（不是"约等于"），否则该 run 作废重跑；
10-seed 复现块的 Wilcoxon p 值必须 < 0.05（n=10 时双侧下限 0.002，n=3 时是 0.25，
所以 3-seed 的 p 值本来就不可能显著，不能拿来当证据）。

**初步证据（`scripts/22_step_matched.py`，用已有日志、不需要新算力）给出两条方向相反的线索，
合起来偏向「数据」那一支，但仍不能定案。**

1. **步数匹配**：把每个 epoch 的 `val_acc` 换算到「优化步数」横轴上后，N=20000 的优势到
   **step ≈ 5500** 才达到最终值的一半，而 N=5000 早在 **step ≈ 3950** 就停止了 ——
   原曲线是在差距刚要出现之前把小样本条件停掉的。单看这条，**算力仍是成立的解释**。
2. **平台诊断**：每个 run 最后 15 个 epoch（正是 patience 窗口）的 val 斜率是「是否还在进步」
   的直接证据 —— **0 / 24 个小样本 run** 在停止时仍以 > +0.002/epoch 上升，N=5000 的窗口内平均
   斜率是 **+0.00025/epoch**；而 N=20000 在末尾也只有 **+0.00066/epoch**。也就是说**每个条件都
   已收敛**，差别在收敛到的**平台高度**（0.51 对 0.77 / 0.66）—— 平台高度是关于刺激的陈述，
   不是关于训练时长的。

合起来：不同样本量**收敛到不同平台高度**，而不是「训练不够久」。唯一尚未排除的情形是
**平坦区之后还有第二次下降**（plateau-then-drop），而这正是等算力网格唯一的职责 ——
给 N=5000 完整 18 780 步，看它是否仍停在 0.51。见 `figures/fig11_step_matched.png`
与报告 6.2b 节（那里也写了三点限定：支持性证据不是对照、短 seed 之外是外推、
以及 3950 步处仍有 +0.021 的小差距不是算力）。

## 7. 主要结果（完整数据见 `reports/report.md`）

训练配置：`core` 电路、ReLU、`w_scale = 1.0`、`α = 0.2`、`T = 8`、AdamW 3e-3、无读出标准化。
N_train = 20000，M1 = 训练突触增益 + 读出，M0 = 冻结网络 + 线性探针。

| 条件 | M1 real | M1 shuffled | Δ | M0 real | 面积基线 | 像素基线 | CNN |
|---|---|---|---|---|---|---|---|
| A 自然 | **0.769** | 0.663 | **+0.106** | 0.504 | 0.557 | 0.506 | 0.9998 |
| B 面积控制 | **0.599** | 0.405 | **+0.194** | 0.202 | 0.200 | 0.200 | 0.976 |
| C 面积+包络 | **0.895** | 0.418 | **+0.477** | 0.171 | 0.200 | 0.230 | 0.999 |
| D 未见布局 | **0.599** | 0.368 | **+0.230** | 0.187 | 0.200 | 0.214 | 0.998 |

**结论**

1. **Level 1 部分达到**：real 在自然条件下达到 0.769（远超所有线性基线，但未到 0.90）。
2. **Level 2 达到**：real 明显优于同参数量的随机化对照（ΔA = +0.106，ΔC = +0.477）。
3. **Level 3 达到**：优势在面积/包络双重控制与未见布局上更强，而非更弱 ——
   说明 real 学到的是**数量**表征，shuffled 学到的更接近亮度/包络捷径。
4. **M0 → M1 是决定性的**：冻结连接组的线性可读性在控制条件下就是 chance
   （B 0.202 / C 0.171 / D 0.187），而 M1 达到 0.599 / 0.895 / 0.599。
   **连接组提供了基底，但数量计算是训练出来的。**
5. **采样效率曲线的「拐点」是算力假象，不是数据量效应。**
   N ≤ 5000 时 real 与 shuffled 在 **60-epoch 预算**下无法区分（Δ 在 ±0.02 内），
   但那是每个 N 都被给了不同算力的结果：N=20000 得 18 780 次更新，N=5000 只得约 4 740。
   把步数对齐后，**N=5000 的 Δ 从 −0.0003 变成 +0.1327**，比 N=20000 的 +0.1075 还大。
   所以**拓扑优势在 5 000 样本上就已存在，且不依赖大样本**；
   「大样本现象」的说法已撤回（详见 §7.5）。
6. **加法（Stage 4-5）没有学会**：训练组合准确率 0.31–0.39（多数类 0.214），
   但留出组合只有 0.00–0.01（chance 0.143）——典型「记住了但没泛化」，
   且 real 与 shuffled 无差别。诊断：加法要求先会数数，而在 8400 样本预算下
   数点本身只有约 0.5。

**主要限定**：`core` 电路只保留 26.4% 的出向突触权重，是「被切除」的制备；
结果回答的是「真实拓扑能否作为 inductive bias」，而不是「果蝇视叶能数点」。

### 7.1 电路完整度阶梯（Stage 6）

`full` 电路保留 91.3% 的出向突触权重（`core` 26.4%），但度数异质性高得多
（最大/平均行和 = 129 vs 59），需要 `--normalization row` 与更小的 `w_scale=0.4`
才能训练；两者固定在 `scripts/run_all.ps1 -Stage 6`。

在 N=5000 上（`core` 在该预算下完全没有 real−shuffled 差距）：

| 条件 | full real | full shuffled | Δ |
|---|---|---|---|
| A 自然 | 0.4874 | 0.4906 | −0.003 |
| B 面积控制 | 0.1832 | 0.1792 | +0.004 |
| C 面积+包络 | 0.1878 | 0.1718 | +0.016 |
| D 未见布局 | 0.1704 | 0.1786 | −0.008 |

**结论**：更完整的电路并没有让优势更早出现 —— 这**倾向于**说明 real > shuffled 是一个
大样本现象，而不是「电路被切除」造成的假象。这与「N ≤ 5000 时 core 也无差距」
一致。**注意**：该解读仍受 §7.2 两条限定约束（随机对照未匹配工作点；原曲线的
N=20000 有四倍算力），`full` 那一档同样是 60-epoch 预算，因此它也带着算力不对称。

两点必须同时声明的限定：① 两档用的归一化不同，所以这不是对「完整度」的干净操纵；
② `full` 的随机化弱得多（与真实图重合 **18.2%**，`core` 只有 2.2%），
所以它的差距若存在会是**保守估计**。要让 `full` 达到同样混合程度需要数倍交换轮数。

### 7.6 加法教学 2×2 pilot：数数预训练帮助「被教」，不帮助「推断」（已完成）

1 seed × 4 组，**每组恰好 10 000 次优化更新**（探针落在 0/500/1000/2000/5000/10000），
除「初始状态」与「是否留出 2+3」外**全部锁死**（种子、数据集、batch 顺序随机源、优化器、
学习率、动力学、读出层初始化）。**显式教学**：和的目标从第 1 步就开启。
温热启动源 `countA01_src` 在**同一 α=0.1** 下训练（test A 0.6376），因此这次不跨积分速率。

| 组别 | seen@2k | seen@5k | seen@10k | operand a@10k | P(5\|2+3) | argmax 2+3 |
|---|---|---|---|---|---|---|
| A1 scratch / 全教 | 0.3495 | 0.4150 | 0.4350 | 0.7650 | 0.3649 | 0.6417 |
| **A2 pretrained / 全教** | **0.4020** | **0.4730** | **0.4900** | **0.8717** | 0.2994 | 0.3200 |
| B1 scratch / 留出 | 0.3425 | 0.4220 | 0.4645 | 0.6183 | 0.1903 | 0.0950 |
| **B2 pretrained / 留出** | **0.3935** | **0.4695** | **0.5305** | **0.8817** | 0.2022 | 0.1167 |

**问题 1：学过数数后加法是否更容易被教会？— 是。** A2 在**每一个**探针点上都领先 A1
（+0.060 / +0.026 / +0.026 / +0.053 / +0.058 / +0.055，平均 **+0.046**，全部为正），
是整条曲线更高，不是末点侥幸。B 组同一排序。

**问题 2：数数基础是否帮助推断没教过的 2+3？— 没有。** B1 的 P(5|2+3)=**0.1903**、
B2=**0.2022**（chance 0.1429），彼此只差 +0.012（单 seed 噪声内）；
**argmax 准确率 0.0950 / 0.1167 双双低于 chance** —— 两个脑都没真的答出 5。

**两个问题分道扬镳之处才是重点**：B2 在第 0 步（尚未做任何加法训练）就已能解码 operand a
（0.4467，B1 为 0.0000），训练后 **0.8817 vs 0.6183** —— 数数预训练把操作数表征磨锐了 **+0.26**，
但这份表征**没有变成组合能力**。这复现了旧课程 `a: 0.39→0.71 而 a+b 仍在 chance` 的观察，
且是在显式教学下，于是瓶颈被定位为：

> **不是「读不读得出两个数」，而是「会不会把它们合起来」。**

限定：仅 1 seed，故 A 组的 +0.055 值得复现，B 组的差异不值得追；两个脑都远未掌握加法
（seen 仅 0.44–0.53），所以「预训练有帮助」是在**学习速率**意义上成立，而非「达到高准确率」。
图见 `figures/fig12_addition_pilot.png`（A 四条教学曲线 / B 两个 Holdout 组的 P(5|2+3) /
C 操作数探针），判定见报告 §6.7。

### 7.5 等优化步数对照：拐点是算力，不是样本量（已完成，**推翻了原解读**）

原曲线给每个 N 都训 60 epoch，于是 N=20000 拿到 18 780 次更新而 N=5000 只有约 4 740 次。
`scripts/15_run_parallel.py --grid fixed_updates` 让每个条件都**恰好**花 18 780 步
（并把验证点数固定为 60，使模型选择粒度可比）：

| N_train | epoch 预算下的 Δ | **等步数（18 780）下的 Δ** |
|---|---|---|
| 5 000 | **−0.0003**（0.5119 vs 0.5122） | **+0.1327**（0.7229 vs 0.5903） |
| 10 000 | — | **+0.1096**（0.7533 vs 0.6437） |
| 20 000 | +0.1075（10 seeds） | —— （该档本就是 18 780 步） |

**结论（按 §6.1 预先锁定的规则判定）**：给 N=5000 同样的算力，real−shuffled 差距从
**−0.0003 变成 +0.1327** —— 落在预先写死的「Δ(5000, 等算力) ≥ 0.06 → 原拐点是算力」
那一支。因此：

- **「N ≤ 5000 时 real 与 shuffled 无差别」是算力造成的假象**，不是数据量的性质。
- **「拓扑优势是大样本现象」这一说法必须撤回。** 真实的连接组优势在 5 000 个样本上
  就已存在，而且**比 20 000 样本时还大**（+0.133 vs +0.108）。
- 精确地说，样本量 5k → 20k 时 real +0.050、shuffled +0.078，**差距反而略微收窄**。
  更多样本对**对照**的帮助比对 real 更大。
- 这对论文的**核心主张是加强**（真实连接组优于同度数同权重的对照，且不依赖大样本），
  只是推翻了「大样本现象」这个具体框架。

这意味着 §7 第 5 条、§7.1 与 §7.3 中所有「N ≤ 5000 无差距」的表述都要按此改写，
`reports/report.md` §6.2 的表已是等步数与 epoch 预算并列呈现。

### 7.4 等谱匹配对照：头条结论是否只是放大倍率的假象？（已完成）

§7.2 曾列出第一条限定：随机对照未在「工作点」上匹配。这一条现在**已被实测闭合**。

`w_scale` 对权重矩阵严格线性，因此把随机图的 `w_scale` 乘以 ρ_real/ρ_shuffled = **1.4106**
即可让它拥有与 real **完全相同**的谱半径（实测残差 **0.000%**），活动增长也只差 12%。
在这个**度数、权重分布形状、谱半径、活动增长四个维度全部对齐、只差边怎么连**的对照上：

| 条件 | seeds | A | B | C | D |

限定（必须同时声明）：① 等谱匹配对照只有 **3 个 seed**（real / 普通对照各 10 个），

### 7.2 已知限制

**本 session 新发现的限定**：

- ~~随机对照并未在「工作点」上匹配~~ —— **已由 §7.4 的等谱匹配对照闭合**：
  匹配后 real 仍领先 +0.070（A）到 +0.422（C），结构贡献占 65%–85%。
  保留下来的限定是：等谱匹配对照只有 3 个 seed，且它的权重量级被整体放大 1.41 倍。
- **样本效率拐点的归因 —— 已由 §7.5 定案：拐点是算力。** 原曲线给了 N=20000 四倍算力，
  对齐后 N=5000 的 Δ 从 −0.0003 变 +0.1327。**「大样本现象」已撤回**；
  第 7 节凡是「N ≤ 5000 无差距」的表述都以此为准。
- **课程的温热启动跨了 α**：源计数模型训在 α=0.2、T=8，课程用 α=0.1、T=14
  （14 步在 α=0.2 下会发散）。`scratch` 对照用同一个 α，所以两者之差仍只反映
  「是否继承递推参数」，但「继承的是 α=0.2 学到的增益」必须写明。

**原有的限制**：

- **递推只是临界稳定**：`core` 在 `w_scale = 1.0` 下 32 步内活动增长约 10⁷ 倍。
  计数能在 t=8 读出，是因为抢在发散之前；这使网络更像**暂态/前馈**计算，
  而不是收敛的循环计算。加法因此必须换更小的 `α`。
- **权重全为正（不区分兴奋/抑制）**：v1 的简化，也是上述不稳定的根源。
  签名突触（`signed_count` 网格）把 48 步的峰值活动从 3.4e9 压到 13.8，是直接的修正。
- **读出只取 VPN**：生物上最干净，但可能丢弃 medulla 中的数量信息；
  `--readout all_except_input` 已实现，尚未系统比较。
- **M0 与 M1 的标准化不对称**：M1 关闭、M0 探针内部开启（线性探针的标准做法）。
